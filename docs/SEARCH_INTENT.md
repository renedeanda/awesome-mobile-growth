# Search intent map

Each route has one primary visitor job. Avoid thin keyword variants.

| Route | Primary job | Promise |
| --- | --- | --- |
| `/` | Understand the approach | A credible map of the whole ASO practice |
| `/aso-checklist/` | Complete a launch review | A practical end-to-end checklist |
| `/guides/metadata/` | Write store metadata | Field-by-field decisions and limits |
| `/guides/keyword-research/` | Research search language | Evidence-aware prioritization |
| `/guides/localization/` | Adapt a listing by market | Meaning-first localization |
| `/guides/screenshots/` | Plan store creative | A visual argument grounded in product proof |
| `/guides/product-page-testing/` | Design a useful test | Decisions, hypotheses, measures, and logs |
| `/guides/ratings-retention/` | Connect acquisition to product quality | A complete post-install feedback loop |
| `/google-play/` | Adapt the strategy for Android | Play-specific fields, policy, and experiments |
| `/workbench/` | Do the work privately | Local drafting, validation, planning, and export |
| `/resources/` | Find trustworthy references | A small maintained source shelf |

Review Search Console at 30, 60, and 90 days. Improve the route that already matches an intent before creating another route. Never turn query variants into near-duplicate pages.
