# Apple metadata

Verify current limits in App Store Connect Help before submission. As of the review date used by this project, common limits are: name 30 characters, subtitle 30, promotional text 170, keywords 100 UTF-8 bytes, description 4,000 characters, and What’s New 4,000 characters.

## Review order

1. Read name, subtitle, first screenshots, and description opening as one promise.
2. Check that the name is distinctive and the subtitle adds meaning instead of repeating it.
3. Use the keyword field for relevant comma-separated terms that are not already carried efficiently elsewhere. Check bytes, not only visible characters.
4. Treat promotional text as a timely conversion surface, not a durable keyword field.
5. Keep What’s New specific to user-visible change and benefit.
6. Flag trademarks, unverifiable superlatives, price claims, and features the build does not support.

Primary sources: Apple App Store Connect Help, “Platform version information” and “Required, localizable, and editable properties.”
