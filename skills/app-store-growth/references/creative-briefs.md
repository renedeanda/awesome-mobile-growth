# Creative briefs

Each frame should have one message and visible proof.

Use this schema: placement, audience question, message, product evidence, capture state, overlay copy, accessibility check, locale status, owner, and source requirement. The first frames should work as a coherent sequence and as isolated impressions.

Do not hide missing product value behind decorative mockups. Keep critical UI and text clear of crop-sensitive edges. Design video to communicate while muted. Verify exact file formats and dimensions in current Apple or Google documentation before export.
